MyLibrary Help — Dashboard, Chrome Extension, CLI, REST API & MCP Server

• Time-Series Charts & Mix-and-Match Review: Click any number on the epubmeta Enrichments card or Local Metadata Cache to view hourly/daily charts. Click any Explorer row to cherry-pick Before vs. After fields, click ✨ AI Generate Description from Content to generate a synopsis from the book's actual pages, open Preview Inside Book (with AI Re-Evaluate from Image(s)), or search/generate covers with Find Covers.
• Web Catalog, Cover Self-Healing & Duplicates Manager (/mylibrary/ & /mylibrary/duplicates/): Search with structured operators (author:, title:, cat:, tag:, isbn:, format:, year:, is:enriched, is:interesting, missing:cover), enrich books on demand (✨ Enrich Now / ✨ Enrich Page), auto-heal partial top-banner or textless background PDF covers on the fly, move periodicals to /toMags, and clean up duplicate enriched files safely.
• OPDS 1.2 & Calibre Content Server (/mylibrary/opds/?v=2): Add http://192.168.1.43:8080/mylibrary/opds/?v=2 in Moon+ Reader. Downloading any unenriched book automatically enriches it on the fly before streaming <Title> - <Author>.epub and migrating Moon+ WebDAV `.po`/`.an` bookmarks.
• Load Unpacked Extension: In Chrome, open chrome://extensions/ → enable Developer mode → Load unpacked → select U:\MyLibrary\chrome_wishlist_extension.
• Amazon Wishlists & Book Product Pages (Amazon, Barnes & Noble, Springer Link, Goodreads, O'Reilly, No Starch + Custom Sites): Displays a live ✅ In MyLibrary / ❌ Not in MyLibrary indicator (with edition & publication-year verification and a ✕ False Positive button), plus Open in Anna's Archive (ISBN), Search in Anna's Archive (Title), 🔍 Check Anna's Live (ISBN + Title), and optional Open in Z-Library. Switch Anna's Archive domains (.pk, .gl, .li, .se, .org) or add custom book sites in 1 click from the extension popup.
